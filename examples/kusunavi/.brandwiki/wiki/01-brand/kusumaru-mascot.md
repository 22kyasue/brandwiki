# くすまる（マスコットキャラクター）

クスナビの公式マスコット。**家庭の薬箱から生まれた、薬カプセルの妖精** という設定で、家族の健康を見守る案内役。

> 設計指示書では「カプくん」という旧名称が使われているが、現行プロダクト内の実装名は **くすまる（Kusumaru）** で統一されている（`Kusumaru.tsx`、i18n `kusumaruMessages` 等）。

## 印象キーワード

やさしい / 安心 / かわいい / 清潔感 / 親しみやすい / 医療っぽすぎない

## 基本プロポーション

- **頭身**: 2〜2.5頭身（チビ・デフォルメ）
- **シルエット**: 縦長の医薬品カプセル型。全身曲線
- **手足**: 短くて丸いミトン状（指なし）
- **サイズ感**: 手のひらに乗るくらい

## カラー（厳密指定）

| パーツ | カラーコード | 説明 |
|---|---|---|
| 体・上半分 | `#E8837C` | ピーチ／コーラル |
| 体・下半分 | `#FFF5EE` | クリーム／オフホワイト |
| 目 | `#3D2C2C` | ダークブラウン（黒ではない） |
| ほっぺ | `#F2A59E` | 淡いピンク |
| 葉っぱ | `#7BC67E` | やわらかいグリーン |
| 手足 | `#FFF5EE` | クリーム |

体上下比率は **上55% : 下45%**。頭頂部にクスノキの葉を1枚（時計1時方向）。

## 表情パターン（7種）

| ID | 表情 | 用途 |
|---|---|---|
| にこにこ | デフォルト・三日月目 | ホーム画面、通常状態 |
| 考え中 | 上目遣い・口元に手 | 症状分析中、ローディング |
| おすすめ！ | キラキラ目・手挙げ | 候補提示、成功時 |
| 注意 | 困り顔・両手前 | 飲み合わせ注意、期限注意 |
| ストップ | 真剣・両手×印 | 禁忌、受診推奨 |
| おめでとう | 万歳ポーズ | 服薬完了、目標達成 |
| ひょっこり | 画面端から覗く | 通知、ヒント、ツールチップ |

## 画風

- フラットデザイン寄り、日本のゆるキャラ／サンリオ系
- 線: やわらかい輪郭線（ブラウン、太すぎない）
- 塗り: フラット、グラデは最小限（チークぼかしのみ）
- **避ける**: リアル3D、厚塗り、アニメ風の複雑な瞳、ホラー、蛍光色

## 役割の哲学（重要）

くすまるは **「ゲーム要素ではなく関係性と振り返り」** で支える存在として位置づけられる。詳細は [[kusumaru-philosophy]] を参照。
