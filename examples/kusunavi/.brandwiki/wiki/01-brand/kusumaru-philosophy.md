# くすまるのデザイン哲学

2026-04-12 のデザイン議論で確定した、くすまるとアプリ全体のトーンに関する重要な方針。

## やること

- **温かさ** — くすまるが文脈に応じて優しく声かけ
- **振り返り** — 数字やバッジではなく、意味のある服薬サマリー
- **存在感** — 最初から最後まで常にそばにいる相棒
- **関係性** — 家族・自分の健康への愛情を後押し

## やらないこと（保留／却下された機能）

| 機能 | 理由 |
|---|---|
| **実績／バッジシステム** | 医療アプリにストリークは有害。入院・旅行で中断 → 罪悪感／無理して服用するリスク（Duolingo型ストリーク依存症の問題） |
| **ストリーク** | 同上 |
| **レベル／XP** | ユーザー動機は「健康・家族への愛」であって、+5XP は薄っぺらい |
| **くすまるの成長／進化** | くすまるは「くすまる」。ロゴ／マーケと画面のキャラが違うとブランド希薄化。「Lv16 まで大人くすまるに会えない」は報酬ではなく罰 |
| **派手な称賛** | 「すごい！」「さすが！」連発は逆効果。落ち着いたトーン維持 |

## 拒否理由（要約）

1. **医療アプリのトーンと合わない** — 大人向けの落ち着いたツールに「レベルアップ✨」は安っぽい
2. **薬を「ゲーム化」するのは本来の服用動機を歪める** — 厚労省／薬剤師会のガイドライン的にも微妙
3. **新規ユーザー体験の悪化** — 最初に「たまご」や「赤ちゃん」を見せられると困惑
4. **報酬じゃなく罰になる** — ゲートされた感覚は本物のくすまるに会えないストレス

## 代わりにやる方針（Step 7-9）

- **声かけバリエーション拡充** — 文脈別フレーズ（連続利用、家族管理、服用、体調気遣い、季節）
- **インサイト／サマリー画面** — 月次サマリー、家族別、飲み忘れパターン分析
- **WeeklyReport の感情面コピー追加** — くすまるが週を振り返るヒーローセクション

> 「くすまるがそばにいてくれる安心感」で支える方向。
