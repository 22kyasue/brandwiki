# クスナビ プロダクト概要・機能一覧

## プロダクト定義

日本の家庭向けOTC医薬品リスク管理アプリ。家庭内のOTC・処方薬を管理し、飲み合わせチェック、症状ベースのトリアージと薬推奨、AIによる薬剤師チャットを提供する。

## バージョンロードマップ（V0〜V2 完了済み）

### V0: 家庭内薬ストック管理基盤
**ゴール**: 「家に何の薬があるか」「いつ切れるか」「どれだけ残っているか」「誰の薬か」が分かる状態を作る。

主な機能:
- 家族プロフィール作成・管理
- 健康プロフィール登録（持病・アレルギー・妊娠授乳・常用薬）
- 薬登録（写真OCR / バーコードスキャン / 手入力 / お薬手帳QR）
- 薬一覧・詳細・編集・削除
- 使用期限管理・残数管理・保管場所管理
- 期限切れ/残数通知

### V1: 症状相談と安全優先の候補整理
**ゴール**: 症状があるときに、家にある薬の中から安全性を優先して整理された結果を返す。

主な機能:
- 主症状選択（16カテゴリ以上）
- 分岐型問診フロー
- 危険サイン確認（レッドフラグ判定）
- 判定エンジン（緊急性→禁忌→重複成分→適応一致の順）
- 候補 / 注意 / 非推奨 / 受診推奨の4分類出力（理由付き）
- 受診推奨画面

### V2: 継続利用性と個別最適化
**ゴール**: 継続的に使える家庭内薬管理・症状支援アプリとして成立させる。

主な機能:
- 服用記録・履歴
- 症状相談履歴・再相談
- 通知強化（再相談促進・服薬リマインダー）

## 主要機能（現在実装済み）

| 機能 | 説明 |
|------|------|
| 薬管理 | OTC/処方薬の登録・一覧・詳細・編集。カメラOCR・バーコード・手入力対応 |
| 飲み合わせチェック | 成分ベースの重複・相互作用チェック。KEGGデータ連携 |
| 症状トリアージ | 分岐型問診 → 危険サイン検出 → 推奨エンジン |
| 疾患推定 | 13種以上の疾患パターンから推定 |
| AIチャット | Claude Haiku による薬剤師チャット |
| 家族管理 | 複数家族メンバー対応。家族グループ共有 |
| 服薬リマインダー | 個別薬ごとのリマインダー設定 |
| データエクスポート | CSV・PDF形式 |
| サブスクリプション | RevenueCat経由（Free / Premium / Family） |

## ナビゲーション構造（メインタブ）

- **ホーム**: ダッシュボード、アラート、クスマルセクション
- **お薬**: 薬一覧・詳細・登録
- **チャット**: AI薬剤師チャット
- **家族**: 家族メンバー管理

## コアユーザーフロー

1. **初期設定**: 家族プロフィール作成 → 健康プロフィール登録
2. **薬登録**: 写真/バーコード/手入力 → 候補確認 → 期限・残数・対象者入力 → 保存
3. **薬管理**: 一覧確認 → 期限切れ/残数不足を把握 → 詳細確認
4. **症状相談**: 対象者選択 → 主症状選択 → 問診回答 → 危険サイン確認 → 判定 → 結果表示
5. **服用記録**: 実際に飲んだ薬を記録 → 次回判定に反映
